# Maid Lifestyle Cleaning Services — Website

Static website (plain HTML/CSS/JS). No server, database, or paid service required.

## What's here
| File | Purpose |
|---|---|
| `index.html` … `contact.html`, `quote.html` | The 7 pages (generated by `build.py`) |
| `assets/css/style.css` | All styling. Brand colors are the variables at the top. |
| `assets/js/config.js` | **Lead email, phone, and customer reviews** — edit here |
| `assets/js/main.js` | Menu, gallery/lightbox, form sending |
| `assets/img/` | Shana's photos (optimized), logo, favicon |
| `build.py` | Edit SETTINGS (domain, service area, Facebook URL) and run to regenerate pages |
| `tools/make_qr.py` | Makes the branded print QR code once the site is live |
| `robots.txt`, `sitemap.xml` | SEO files (regenerate after setting `SITE_URL`) |

## Before launch — fill these in `build.py`, then run `python3 build.py`
1. `SITE_URL` — the final domain (enables canonical links, social previews, sitemap).
2. `SERVICE_AREA` — e.g. "Goose Creek, Summerville & Greater Charleston, SC" (adds local SEO + shows on Contact).
3. `FACEBOOK_URL` — the real Facebook page link (currently a Facebook search link so it isn't broken).

## Forms (quote, commercial inquiry, contact)
Submissions are emailed to **themaidlifestylecompany@gmail.com** through **Web3Forms** (free, 250 submissions/month, no account).
- Get the access key at https://web3forms.com (enter the business email; the key is emailed there).
- Paste it into `web3formsKey` in `assets/js/config.js`, commit, and Render redeploys automatically.
- Until a key is set, or if a send fails, visitors see an error with the phone number and email — never a fake success.
- Check Spam for the first few submission emails and mark them "Not spam".

## Deploying (free options)
**Netlify (easiest):** netlify.com → Add new site → *Deploy manually* → drag this whole folder in. Then Domain settings → add your custom domain.
**Cloudflare Pages / GitHub Pages / Render Static Site:** upload/push this folder; no build command, publish directory = `/` (the folder root).
Any regular web host also works — upload all files keeping the folder structure.

Then:
1. Set `SITE_URL` in `build.py`, run `python3 build.py`, and re-upload.
2. Run `python3 tools/make_qr.py https://YOUR-DOMAIN` for the print QR code.
3. Submit the sitemap in Google Search Console and create/claim a Google Business Profile (biggest local-SEO win).

## Adding reviews
Edit `ML_REVIEWS` in `assets/js/config.js` with **real** customer reviews only (with their permission).

## Adding photos
Put a photo in `assets/img/` as `name-lg.jpg` (~1600px) and `name-sm.jpg` (~700px), then add a line to
`GALLERY` in `build.py` with its categories (`kitchen bathroom living bedroom deep beforeafter`). Only use
`beforeafter` for true matching before/after photos of the same job.
